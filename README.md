## Projetos selecionados

- [**SophIA — Lousa Inteligente**](https://github.com/FaelDev-ux/lousa-sophia) — lousa digital que interpreta expressões matemáticas desenhadas e explica a resolução passo a passo com IA e visão computacional. [Ver aplicação](https://lousa-sophia.vercel.app/).
- [**CryptoSafe**](https://github.com/FaelDev-ux/cryptosafe) — aplicação que analisa o risco de transações cripto antes da assinatura, combinando regras determinísticas e sinais on-chain. [Ver aplicação](https://cryptosafe-gamma.vercel.app/).
- [**Personal Finance**](https://github.com/FaelDev-ux/personal-finance) — painel de finanças pessoais com autenticação, transações, categorias e persistência de dados via Supabase. [Ver aplicação](https://personal-finance-two-drab.vercel.app/).
- [**Resgata Pets**](https://github.com/FaelDev-ux/resgatapet) — plataforma para registrar situações envolvendo animais e organizar informações para o acompanhamento das ocorrências. [Ver aplicação](https://resgata-pets.web.app/).
- [**R2 Labss**](https://www.r2labss.dev/) — estúdio digital de landing pages, sites institucionais, portfólios e interfaces web com identidade própria.
